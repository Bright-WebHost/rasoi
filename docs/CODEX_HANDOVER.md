## Architecture (as built)

YCloud → `app/api/webhooks/ycloud/whatsapp/route.ts` (HMAC verify) → `ycloud_event_inbox`
(unique per event id and inbound message id) → forwarder `lib/server/ycloud-forwarder.ts`
(runs via `after()`, opt-in) → n8n `rasoi-whatsapp-inbound` webhook (Header Auth
`x-rasoi-whatsapp-secret`) → Order Bridge → Rasoi `/api/ai/tools/*` (header `x-rasoi-ai-secret`) and
Supabase REST → YCloud send.
Retries: n8n `Rasoi | Inbox Drain — DEV` calls `POST /api/internal/ycloud-inbox/drain` every minute
(Vercel Hobby cron is daily-only). Claims use `claim_ycloud_events`/`finish_ycloud_event` (lease,
fencing on `attempts`, backoff 30s·2ⁿ ≤ 1h, `failed` after 8).

## Gotchas

- n8n public API: `GET /workflows/{id}` does not return folder; create with `projectId` +
  `parentFolderId`. Folders API needs `folder:*` scopes the key lacks.
- n8n `toolHttpRequest` v1.1 silently drops tool calls with a JSON-array placeholder; use scalars.
- Git Bash heredocs mangle `\\` in inline Python regexes — write scripts to files. Windows console
  is cp1252: call `sys.stdout.reconfigure(encoding='utf-8')` before printing ₹. Use `python -I`.
- Next.js here is a newer version; read `node_modules/next/dist/docs/` before using APIs (AGENTS.md).
